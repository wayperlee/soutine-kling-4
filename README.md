# Soutine Kling 4

**Model page:** [https://soutine.ai/models/kling-4](https://soutine.ai/models/kling-4)

Kling 4.0 generation is **not available on Soutine yet**. The page is a coming-soon landing: it compares the announced Kling 4.0 / 4.0 Flash specs with what you can run today.

The generator on that page currently uses **Kling 3.0** (text-to-video, start/end frames, optional audio, about 3–15 seconds, 720p / 1080p / 4K). Credits are spent on generation; you can see an estimate before you submit. Soutine has not published a date for Kling 4.0 access.
